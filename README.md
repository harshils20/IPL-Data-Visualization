# 🏏 IPL Data Visualization Project

## 📌 Project Overview

This project focuses on exploring and visualizing Indian Premier League (IPL) match data using Python. The goal is to identify meaningful patterns and insights related to team performance, match outcomes, player achievements, toss decisions, and match venues through data analysis and visualization.

The project uses Python libraries such as **Pandas, NumPy, Matplotlib, and Seaborn** to perform exploratory data analysis (EDA) and create informative visualizations.

## 🎯 Objectives

- Analyze the number of matches won by each IPL team.
- Explore toss decision trends.
- Examine the relationship between toss winners and match winners.
- Compare matches won by runs versus wickets.
- Identify players with the most Player of the Match awards.
- Analyze top-scoring batsmen.
- Explore the best bowling figures.
- Identify venues that hosted the most matches.
- Find the highest victory margin by runs.
- Identify the highest individual score in the dataset.

## 📊 Key Analysis and Visualizations

The project includes the following analyses:

1. **Team Performance Analysis** – Visualizes the number of matches won by each team.
2. **Toss Decision Analysis** – Examines teams' decisions to bat or field after winning the toss.
3. **Toss vs. Match Results** – Calculates the percentage of matches in which the toss winner also won the match.
4. **Victory Method Analysis** – Compares wins by runs and wickets.
5. **Player of the Match Analysis** – Highlights the top 10 players by award count.
6. **Top Scorers Analysis** – Identifies leading run scorers based on the available high-score data.
7. **Bowling Performance Analysis** – Examines bowlers with the highest recorded wicket counts in their best bowling figures.
8. **Venue Analysis** – Identifies venues with the most matches.
9. **Highest Winning Margin** – Finds the largest victory margin in runs.
10. **Highest Individual Score** – Identifies the player with the highest individual score in the dataset.
